# SpeakFlow — прототип ИИ-репетитора английского

Интерактивный mobile-first прототип в стиле RAW English / SpeakFlow. Основной мобильный размер — 390×844; предусмотрена адаптация под десктоп.

## Запуск

Нужен Python 3:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. Сборка и установка зависимостей не нужны.

## Экраны

Кнопка «Все экраны» открывает обзор 14 макетов с подписями:

- Онбординг: уровень, цель, выбор репетитора.
- Главная и состояние исчерпанного лимита минут.
- Разговор: подключение, ИИ говорит, ученик говорит, нет доступа к микрофону. Дополнительно доступно состояние «думаю».
- Итоги урока с исправлениями и добавлением новых слов.
- Прогресс, словарь, тарифы и профиль.

## Реализовано

Навигация, выбор сценария и репетитора, переключение состояний разговора, таймер, подсказки, озвучка примеров через Speech Synthesis API, поиск и сохранение слов и настроек в localStorage.

## Ограничения прототипа

Живой ИИ-звонок, распознавание речи, платёжный сервис и push-уведомления не подключены. Оценки уроков, история, серия дней и лимиты минут — демонстрационные данные. Проверка разрешения на микрофон сразу освобождает полученный аудиопоток; запись не ведётся.

Шрифты Inter и Gluten загружаются через Google Fonts, фотографии — с Unsplash. Для них и браузерной озвучки может требоваться интернет. Кириллические символы, отсутствующие в Gluten, отображаются резервным шрифтом Inter.

## Файлы

- `index.html` — страница и подключение ресурсов.
- `style.css` — компоненты, состояния и адаптивная вёрстка.
- `app.js` — экраны и логика прототипа.
- `raw-glass.css` — обновлённая тема: тёплый фотофон, тёмные стеклянные панели, лаймовые и красные кнопки.
